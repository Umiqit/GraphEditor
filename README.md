# GraphEditor

Графический редактор на Java (Swing). Реализованы инкременты 1 и 2:
растровый редактор и векторный редактор с декораторами оформления.

## Возможности

### Инкремент 1 — растровый редактор

- Рабочая область для создания изображения (FR-1.1).
- Инструменты: точка, круг, квадрат; выбранный инструмент подсвечивается (FR-1.2, FR-1.9).
- Рисование мышью: при удержании левой кнопки элементы повторяют путь движения
  курсора выбранным цветом (FR-1.3, FR-1.4); круг и квадрат рисуются протягиванием,
  как в Paint, с предпросмотром.
- Одновременное отображение множества элементов разных типов (FR-1.5–FR-1.7).
- Кнопка «Очистить» — удаление всех элементов (FR-1.8).
- Модель: абстрактный класс `Pixel` и наследники `Point`, `Circle`, `Square`;
  создание элементов вынесено в фабрику `PixelFactory`.

### Инкремент 2 — векторный редактор

- Инструмент «Полигон»: щелчки задают вершины (минимум 3),
  двойной щелчок завершает фигуру (FR-2.1–FR-2.3).
- Оформление независимыми декораторами (FR-2.4–FR-2.7):
  заливка (`FillDecorator`), контур (`BorderDecorator`), тень (`ShadowDecorator`);
  произвольные комбинации и порядок без изменения класса `Polygon`.
- Инструмент «Выбор»: щелчок выбирает фигуру (рамка с маркерами),
  повторный щелчок и перетаскивание перемещают её;
  оформление выбранной фигуры меняется палитрами (FR-2.8).
- Инструмент «Ластик»: стирает фигуры при протягивании мыши (FR-2.11).
- Палитры цветов как в Paint и диалог своего цвета RGB (FR-2.12).
- Растровые и векторные элементы в одном рисунке (FR-2.10).

## Запуск

Требуется JDK 17+. Двойной клик по `run.bat` (запуск) или `test.bat` (тесты),
либо вручную:

```bash
javac -encoding UTF-8 -d out $(find src test -name "*.java")
java -cp out ru.grapheditor.TestRunner
java -cp out ru.grapheditor.ui.GraphEditor
```

## Структура

```text
src/ru/grapheditor/
├── pixel/   # Pixel (abstract), Point, Circle, Square, PixelType, PixelFactory
├── shape/   # Shape, Drawing, Polygon, ShapeDecorator, Fill/Border/ShadowDecorator
└── ui/      # GraphEditor, Canvas, Tool, ToolSelector,
             # DecorationOptions, ColorPalette, CustomColorDialog
test/ru/grapheditor/TestRunner   # тесты T1–T15 и T2-01–T2-13
docs/                            # UML-диаграммы, описание проверки
```
