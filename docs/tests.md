## Инкремент 3 — тестовый набор (TestRunner, метод `increment3`)

| Группа | Проверяемое | Реализация |
|---|---|---|
| Команды | execute/undo/redo создания, сдвига, удаления, очистки, lambda-команды | модель + `History` |
| Настройки | фон, контур и тень из `Settings` → `DecorationOptions` → `Canvas.applySettings` | headless-конструктор `Canvas` |
| Хранилища | roundtrip всех форматов из `Storages.ALL` (`ged`, `txt`, `png`, `jpg`): состав, координаты, вершины, цепочка декораторов | временные файлы, сравнение `sameContent` |
| Хранилища | порченый `*.txt` и PNG без метаданных → `IOException` | негативные сценарии |
| draw.io | выбор кликом, перетаскивание с первого нажатия и его отмена | синтетические `MouseEvent` на `Canvas` |
| draw.io | ресайз круга за уголок рамки и его отмена | `MouseEvent`, проверка радиуса |
| draw.io | перетаскивание вершины полигона за ручку и его отмена | `MouseEvent`, проверка вершин |
| draw.io | ластик удаляет фигуру под курсором | `MouseEvent` в режиме ERASER |
| Полигон | клик по первой вершине замыкает фигуру (3 вершины, без лишней точки) | `MouseEvent` + `setDecorationChoice` |
| Полигон | выбор оформления: заливка / только контур; отмена создания | проверка цепочки декораторов |

## Запуск

```bash
javac -encoding UTF-8 -d out $(find src test -name "*.java")
java -cp out ru.grapheditor.TestRunner
```

Ожидаемый результат: все проверки PASS, код выхода 0.
